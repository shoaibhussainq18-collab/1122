# TECH TRACKER - Luxury Watches, Smartwatches & Gadgets Store

A complete e-commerce solution for **TECH TRACKER** with luxury Hublot replicas, smartwatches, airbuds, and gaming accessories.

## Features
- **Interactive Storefront (`index.html`)**: Complete with cart drawer, Cash On Delivery (COD) quick checkout modal, order tracking, search filter, and strap color switcher.
- **Shopify 1-Click Import CSV (`shopify_products.csv`)**: Formatted to official Shopify import specifications (46 columns including handles, HTML body, tags, SKUs, and pricing).
- **Spreadsheet CSV (`products.csv`)**: Standard tabular format for Excel / Google Sheets with PKR pricing, ratings, discounts, and inventory status.
- **JSON Catalog (`products.json`)**: Machine-readable catalog for custom apps and APIs.
- **Python Scraper (`scraper.py`)**: Automated extraction script to re-parse or update the catalog anytime.

## How to Import to Shopify
1. Open **Shopify Admin** -> **Products**.
2. Click **Import** in the upper right.
3. Choose `shopify_products.csv` and click **Upload and continue**.
4. Review preview and click **Import products**.
